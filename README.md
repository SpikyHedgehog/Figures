# Figures
Простое приложение для отрисовки фигур


Попытался реализовать простое добавление фигур - они наследуются от базового класса Figure.
Но так же я подумал о том, что необязательно привязываться к конкретной платформе отображения. Сейчяас мы хотим в WPF,
завтра захотим выводить в консоль,послезавтра в веб, а ещё через месяц захотим ещё как-нибудь.
Потому слой рендера тоже сделал абстракнтым и реализовал через паттерн "посетитель".
Теперь для добавления новой фигуры нужно просто добавить новый класс фигуры и реализовать метод accept,
а для добавления нового рендера нужно реализовать новый класс рендера и реализовать методы visit для каждой фигуры.

Сейчас реализован набор базовых фигур - круг, эллипс, прямоугольник, квадрат, треугольник. 
И реализовано для рендера - один для WPF, второй для логгирования. Подключен тот, который для WPF.
Подключение происходит через DI.

Структура проекта:
Figures.Core - базовые фигуры, абстракции - базовый рендер, базовый класс фигуры, интерфейс посетителя
Figures.WPF - реализация рендера для WPF
Figures.Logger - реализация рендера для логгирования
Figures.App - точка входа в приложение, в настоящий момент реализовано как WPF.

Фигуры захардкожены для примера, контролов никаких нет.
